# Tutorial foundation and project-specific additions

The CRM/ERP dataset layout, Bronze/Silver/Gold learning project and business requirements come from materials supplied with the SQL warehouse and analytics tutorial by Baraa Khatib Salkini. The supplied materials carry the MIT licence, copyright 2024 Baraa Khatib Salkini; that notice is retained in `docs/UPSTREAM_LICENSE`.

The existing repository started with Bronze SQL and setup instructions. This continuation adds safe database initialization, reproducible source preparation, transaction rollback, load auditing, exclusion reporting, automated integration checks and documented analytical definitions. It should be presented as a tutorial-based implementation extended and validated for a portfolio, not as an original client engagement or a production warehouse.

Original source extracts and downloaded reference solutions are not redistributed here. Public regression fixtures are small fictional records generated specifically for this project.
